Extract each `raw_events/<eventId>.txt` Facebook event into `page/events.json`.

This catalog is running, cycling, and triathlon events only.

## Skip (do not add; delete the raw file)
Club socials, meetings, recruitment, parties, dinners, academic contests, and anything that is not a run/ride/tri race or endurance event. `pnpm check` requires a 1:1 match between raw files and `fbLink` IDs, so skipped IDs must not leave a `.txt` behind.

## Fields
- name, date, distance (km number only, e.g. 21.1 / 10 / 5), location, fee, earlyBirdFee, website, tags, responseCount, fbLink
- location: comma-separated; omit "Bangladesh"
- tags: comma-separated (e.g. AIMS); null if unknown
- null for any missing field

## Multi-distance (critical)
One FB event with multiple race distances → one JSON object per distance.
Fees often differ by distance — use the fee for that distance only.

**name MUST end with ` | {distance}k`** (lowercase k). Same base title, different suffix:
- `Turkish Airlines ActivePulse International Half Marathon 2026 | 21.1k`
- `Turkish Airlines ActivePulse International Half Marathon 2026 | 14.6k`
- `Turkish Airlines ActivePulse International Half Marathon 2026 | 7.3k`
WRONG: identical names with no suffix (looks like duplicates).
If the title already has other `|` parts, still append distance last:
`Dhaka 25k 2027 | 4th Edition | 25k`

Single-distance events: still append `| {distance}k` when distance is known.

## Process
1. Skip an eventId if it already appears in any `fbLink` in `events.json` (unless refreshing/updating).
2. Read each raw file yourself — no extraction scripts.
3. After each file, append/update `page/events.json` immediately.
